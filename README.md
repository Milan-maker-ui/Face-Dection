👤 Face Detection System using OpenCV

A real-time Face Detection System built with Python and OpenCV. The application detects human faces from a webcam or image using Haar Cascade classifiers and draws bounding boxes around detected faces.

📌 Features

- 🎥 Real-time face detection using webcam
- 🖼️ Detect faces in images
- ⚡ Fast and lightweight implementation
- 📦 Easy to install and run
- 🐍 Built entirely with Python and OpenCV

🛠️ Tech Stack

- Python 3.x
- OpenCV
- NumPy

📷 How It Works

1. Opens the webcam.
2. Captures video frames in real time.
3. Converts each frame to grayscale.
4. Detects faces using the Haar Cascade classifier.
5. Draws a rectangle around each detected face.
6. Press Q to exit.

📸 Output

- Detects one or multiple faces in real time.
- Displays bounding boxes around detected faces.
